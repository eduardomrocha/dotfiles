# Coding Basics

## Follow Conventions

- Match the existing code style, structure, and patterns in the project
- Use the same libraries, frameworks, and utilities already present
- Do not add new dependencies without asking first

## Atomic Changes

- Make one logical change per step
- Keep changes focused and reviewable
- Commit related changes together, unrelated changes separately

## Security

- No hardcoded secrets, keys, or tokens
- Validate all inputs
- Handle errors gracefully, never expose internals to users

## Clean Code

- Meaningful, descriptive names
- Small, focused functions
- No dead code, commented-out code, or console.logs
- Keep it simple — prefer the simplest correct solution
